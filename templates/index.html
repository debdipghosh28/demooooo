      ESP32 or Arduino Uno not showing in Windows Device Manager?

      If your device does not appear under Device Manager → Ports (COM & LPT), follow these 3 steps:

      1. Install the USB-to-UART Driver (Required for Windows to create a COM port):
        CH340 / CH341 Driver (WCH Official) • Common for ESP32 & Uno Clones CP2102 / CP2104 Driver (Silicon Labs) • NodeMCU & ESP32 DevKit FTDI VCP Driver • FT232 USB Serial
      2. Check Your USB Cable: Many micro-USB and USB-C cables are charge-only (lack data lines). Use a verified data sync cable.
      3. PlatformIO in Cursor / VSCodium: Once the driver is installed and the board is plugged in, PlatformIO will automatically detect the port. You can upload with:
        pio run -e esp32dev -t upload (for ESP32) or pio run -e uno -t upload (for Arduino Uno)
